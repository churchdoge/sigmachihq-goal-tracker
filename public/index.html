Staff

Goals are shared and editable by anyone with this page open — the same record every manager and reviewer works from. Each objective is a qualitative outcome broken into 2-4 measurable key results; "On Track / At Risk / Blocked / Complete" are logged per quarter per key result, and an objective's own status rolls up from its worst-off key result (any Blocked key result blocks the objective; otherwise any At Risk key result puts it at risk; it's Complete only once every key result is). The annual rating is set per objective at year-end review. Quarters follow SigmaChiHQ's fiscal year (July 1 – June 30): Q1 = Jul–Sep, Q2 = Oct–Dec, Q3 = Jan–Mar, Q4 = Apr–Jun, with the annual review running each June. See the Evaluation Framework master document for the full scoring process.
